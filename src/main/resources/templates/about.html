About The Pantry

The Pantry is a recipe search web app that displays recipes based on ingredients the user has available. Users may also create an account to manage recipes and save favorites, with passwords protected using BCrypt hashing.

The Pantry Development & Testing

This site was developed as a Liftoff group portfolio project to display knowledge learned from the LaunchCode LC101 course.
